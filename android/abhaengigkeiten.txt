# Fremdmodule der Kotlin-/Java-Seite — mit Lizenz.
#
# Diese Datei ist die Erlaubnisliste für `scripts/abhaengigkeiten-pruefen.sh`.
# Der Job löst den Gradle-Graphen der beiden Android-Module auf und hält die
# gefundenen Module dagegen: fehlt eins hier, endet er rot — auch ein
# transitives Modul. Eine neue Abhängigkeit kommt damit nicht unbemerkt herein,
# und wer eine hebt, trägt ihre Lizenz ein. Dieselbe Bauart wie `deny.toml`:
# die Entscheidung ist menschlich, die Prüfung mechanisch.
#
# Aufgenommen sind die Module aus `:bindings runtimeClasspath`,
# `:bindings testRuntimeClasspath`, `:app releaseRuntimeClasspath` und
# `:app debugUnitTestRuntimeClasspath`; gemessen am 18.11.2026, 104 Module.
# Die Lizenzen stammen aus den POMs der Module (abgelesen, nicht behauptet).
# Zwei POMs führen keine Lizenz; bei ihnen steht in der Zeile, worauf die
# Angabe dann beruht.
#
# Format: <group>:<module>  <Lizenz>  [# Anmerkung]
#
# Die Fassung steht bewusst nicht hier: die Liste sagt, *was* fremd ist, nicht
# in welcher Version — die aufgelösten Fassungen stehen im Log des Laufs.
